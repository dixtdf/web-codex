# Web Codex v0.1.0

[English](#english) · [简体中文](#简体中文)

## English

Web Codex 0.1.0 is the first desktop release: a local Codex-grade MCP workspace for Web ChatGPT on Windows, macOS, and Linux.

### Highlights

- Project registration, project-scoped file tools, AGENTS.md/agent.md instructions, native shells, and observable background tasks.
- stdio and Streamable HTTP downstream MCP aggregation with namespaced tool discovery and forwarding.
- Dedicated OpenAI Tunnel page requiring only Tunnel ID and a write-only API Key. The checksum-verified official `openai/tunnel-client 0.0.19` is bundled; no system `openai` command is required.
- Tunnel preflight, environment-referenced Gateway authentication, `/readyz` health checks, dynamic proxy support, and detailed JSONL connection diagnostics.
- OS-protected secret storage, remote operation auditing, command policy controls, and emergency stop.
- Six desktop views, branded Bot icons, and a system tray with panel toggle and runtime actions.

### Validation

- 103 unit/service tests and 12 MCP end-to-end tests passed.
- The official local Tunnel control plane completed initialize, discovery of 17 tools, and `project_list` against the real Runtime.
- Six-page production Electron UI smoke passed with no runtime errors or horizontal overflow.
- Installed Windows Tunnel reached `/readyz = 200 ready` with real credentials. No interactive ChatGPT page success is claimed without a user-facing tool call.

### Install

Download the artifact for your operating system and architecture. Windows packages request administrator privileges through standard UAC. Packages are unsigned in this release.

After starting Web Codex, add a project, enter the Tunnel ID and API Key, start Tunnel, then add a custom MCP server in ChatGPT using **Tunnel + No Auth**.

## 简体中文

Web Codex 0.1.0 是首个桌面发布版，为 Windows、macOS 和 Linux 上的 Web ChatGPT 提供 Codex 级本地 MCP 工作区。

### 主要能力

- 项目登记、项目内文件工具、AGENTS.md/agent.md 指令、原生 Shell 和可观察后台任务。
- 聚合 stdio 与 Streamable HTTP 下游 MCP，支持命名空间工具发现和转发。
- 独立 OpenAI Tunnel 页面，只需 Tunnel ID 和只写 API Key。安装包内置经过校验的官方 `openai/tunnel-client 0.0.19`，不再依赖系统 `openai` 命令。
- Tunnel 预检、环境变量引用的 Gateway 认证、`/readyz` 健康检查、动态代理及完整 JSONL 连接日志。
- 操作系统加密密钥存储、远程操作审计、命令策略和紧急停止。
- 六个桌面视图、统一 Bot 品牌图标，以及支持面板开合和快捷操作的系统托盘。

### 验证结果

- 103 个单元/服务测试和 12 个 MCP 端到端测试全部通过。
- 官方本地 Tunnel 控制面已对真实 Runtime 完成 initialize、17 个工具发现和 `project_list`。
- 六页面生产 Electron UI 冒烟通过，无运行时错误或横向溢出。
- Windows 安装版已使用真实凭证达到 `/readyz = 200 ready`。未把该状态冒充为 ChatGPT 页面内工具调用成功。

### 安装

下载对应操作系统和架构的安装包。Windows 安装包通过正常 UAC 请求管理员权限。本发布版暂未进行代码签名。

启动 Web Codex 后添加项目，填写 Tunnel ID 和 API Key 并启动 Tunnel，然后在 ChatGPT 中通过 **Tunnel + No Auth** 添加自定义 MCP 服务。
