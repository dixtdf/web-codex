# Web Codex v0.2.0

## English

Web Codex 0.2.0 expands the local workspace with binary artifacts and attachment transfer, and fixes modern ChatGPT discovery compatibility.

### Highlights

- Modern `server/discover` support for ChatGPT plugins, with 24 workspace tools discovered through the official Tunnel client.
- Chunked binary read/write with SHA-256 verification for STEP, STL, KiCad, images, and other files.
- Safe ZIP creation and extraction with traversal, entry-count, and size limits.
- Attachment inbox on the Projects page: drag in chat attachments or ZIP files, then ask ChatGPT to copy or extract them directly without Base64.
- Native File/Edit menu bar hidden on Windows and Linux for a cleaner application panel.
- Linux AppImage and deb artifact naming fixed, so releases now publish Windows, macOS, and Linux packages.
- JSONL audit logs continue to redact file contents, Base64 chunks, credentials, headers, and environment values.

### Verification

- 112 unit/service tests and 13 MCP end-to-end tests passed.
- Official local Tunnel control plane verified `server/discover`, initialize, 24-tool discovery, `project_list`, and byte-identical attachment copying.
- Packaged Windows application returned HTTP 200 for `server/discover`; attachment inbox and six-page UI smoke passed.

Packages are unsigned in this release.

## 简体中文

Web Codex 0.2.0 增加二进制产物与附件传输能力，并修复新版 ChatGPT 发现协议兼容性。

### 主要更新

- 支持 ChatGPT 插件的现代 `server/discover` 协议，官方 Tunnel 客户端可发现全部 24 个工作区工具。
- 支持 STEP、STL、KiCad、图片等二进制文件的分块读写与 SHA-256 校验。
- 支持安全 ZIP 创建与解压，包含路径穿越、文件数量和解压大小限制。
- “项目”页新增附件收件箱：拖入聊天附件或 ZIP 后，可让 ChatGPT 直接复制或解压，无需 Base64。
- Windows 与 Linux 隐藏原生 File/Edit 菜单栏，界面更简洁。
- 修复 Linux AppImage 与 deb 的产物命名，使 Release 同时发布 Windows、macOS 和 Linux 安装包。
- JSONL 审计日志继续脱敏文件正文、Base64 分块、凭证、请求头和环境变量。

### 验证结果

- 112 个单元/服务测试和 13 个 MCP 端到端测试通过。
- 官方本地 Tunnel 控制面已验证 `server/discover`、initialize、24 个工具发现、`project_list` 及附件逐字节复制。
- Windows 打包版 `server/discover` 返回 HTTP 200，附件收件箱与六页面 UI 冒烟验证通过。

本发布版暂未进行代码签名。
