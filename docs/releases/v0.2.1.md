# Web Codex v0.2.1

## English

Web Codex 0.2.1 is the completed three-platform release for the 0.2 feature set.

- Adds the package author email required by Linux deb packaging.
- Publishes Windows, macOS, and Linux AppImage/deb packages from the same tag.
- Includes modern `server/discover`, 24 workspace tools, chunked binary transfer, safe ZIP handling, and the attachment inbox.
- Hides the native File/Edit menu bar on Windows and Linux.

Release packages are unsigned.

## 简体中文

Web Codex 0.2.1 是 0.2 功能集的完整三平台发布版。

- 补充 Linux deb 打包要求的标准作者邮箱与维护者信息。
- 同一标签发布 Windows、macOS 和 Linux AppImage/deb 安装包。
- 包含现代 `server/discover`、24 个工作区工具、二进制分块传输、安全 ZIP 与附件收件箱。
- Windows 和 Linux 隐藏原生 File/Edit 菜单栏。

本发布版暂未进行代码签名。
