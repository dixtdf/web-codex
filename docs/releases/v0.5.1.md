# Web Codex v0.5.1

> **Local/unreleased patch build.** Windows packages are unsigned. This version is not pushed or published.

## English

Web Codex 0.5.1 continues the Desktop deep-test hardening with more precise file pagination, composable search filters, and stronger protocol regression checks.

### Fixes and improvements

- `file_read` now returns explicit `actualOffset` and consumed `bytes` in addition to `requestedOffset`, `nextOffset`, and the backward-compatible `offset` field.
- `file_search` supports up to 100 project-relative POSIX-style `includeGlobs` and `excludeGlobs`, composed with `.gitignore` handling and cursor pagination.
- Nested `remoteShell` policy objects reject unknown fields, matching the strict top-level tool schemas.
- MCP E2E tests verify `additionalProperties=false` for every tool and cover all QA-highlighted safety, output, filtering, and pagination parameters.
- `docs/MCP_TOOLS.md` documents how PowerShell 5.1 must use `Get-Content -Raw -Encoding UTF8` for UTF-8 files without BOM.

### Verification

- 150 tests passed: 133 core/service tests and 17 MCP end-to-end tests.
- Coverage: 93.46% lines, 81.30% branches, 90.86% functions.
- Official local Tunnel control plane verified version 0.5.1, 58 tools, `project_list`, and byte-identical attachment copy.
- Production Electron UI smoke passed with `appVersion=0.5.1`, all six pages, and no runtime errors or horizontal overflow.

Shell commands still have full desktop-user authority. No OS-level sandbox, interactive approval system, full PTY, GUI automation, automatic updates, or code signing is included.

## 简体中文

> **本地未发布补丁构建。** Windows 安装包未签名；本版本未推送、未发布。

Web Codex 0.5.1 继续根据 Desktop 深度测试加强文件分页、组合搜索过滤和协议回归检查。

### 修复与改进

- `file_read` 在 `requestedOffset`、`nextOffset` 和向后兼容的 `offset` 之外，新增明确的 `actualOffset` 和实际消费 `bytes`。
- `file_search` 支持每组最多 100 个项目相对 POSIX 风格 `includeGlobs` 和 `excludeGlobs`，可与 `.gitignore` 和游标分页组合使用。
- 嵌套 `remoteShell` 策略对象拒绝未知字段，与严格的顶层工具 Schema 保持一致。
- MCP E2E 测试验证每个工具均为 `additionalProperties=false`，并覆盖报告指出的安全、输出、过滤和分页参数。
- `docs/MCP_TOOLS.md` 已说明 PowerShell 5.1 读取无 BOM UTF-8 文件时需使用 `Get-Content -Raw -Encoding UTF8`。

### 验证结果

- 共 150 个测试通过：133 个核心/服务测试和 17 个 MCP 端到端测试。
- 覆盖率：行 93.46%，分支 81.30%，函数 90.86%。
- 官方本地 Tunnel 控制面验证了 0.5.1、58 个工具、`project_list` 和字节一致的附件复制。
- 生产 Electron UI 冒烟确认 `appVersion=0.5.1`，六页面通过，无运行时错误或横向溢出。
