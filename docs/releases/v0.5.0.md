# Web Codex v0.5.0

> **Local/unreleased build.** Windows packages are unsigned. This version is not pushed or published.

## English

Web Codex 0.5.0 consolidates the expanded 58-tool local workspace and strengthens destructive-operation safety, protocol consistency, incremental output, search, and project diagnostics.

### Highlights

- `file_delete` supports non-mutating `dryRun` and `expectedSha256`; stale file versions cannot be deleted.
- Workspace MCP input schemas reject unknown top-level arguments instead of silently ignoring misspelled safety options.
- `file_search` returns deterministic `{ matches, nextCursor }` pages and honors root `.gitignore` rules by default.
- Shell task output supports reliable UTF-8-safe incremental reads with requested/actual offsets.
- `project_list` reports live filesystem health separately from the enabled registration state.
- Shell and structured-process descriptions explicitly disclose full desktop-user authority and the absence of project sandboxing.
- The workspace retains structured processes, pipe stdin, persisted tasks, Git workflows, binary transfer, recoverable trash, attachment inbox, host diagnostics, and downstream MCP Resources/Prompts.

### Verification

- 149 tests passed: 132 core/service tests and 17 MCP end-to-end tests.
- Coverage: 93.45% lines, 81.11% branches, 90.84% functions.
- Official local Tunnel control plane verified 58 tools, `project_list`, and byte-identical attachment copy.
- Production Electron UI smoke passed across all six pages with no runtime errors or horizontal overflow.

## 简体中文

> **本地未发布构建。** Windows 安装包未签名；本版本未推送、未发布。

Web Codex 0.5.0 整合了包含 58 个工具的本地工作区，并加强破坏性操作安全、协议一致性、增量输出、搜索和项目诊断能力。

### 主要更新

- `file_delete` 支持不修改文件的 `dryRun` 和 `expectedSha256`，旧版本哈希不能删除当前文件。
- 工作区 MCP 输入 Schema 拒绝未知顶层参数，不再静默忽略拼错的安全选项。
- `file_search` 返回确定性的 `{ matches, nextCursor }` 分页结果，并默认遵守项目根目录 `.gitignore`。
- Shell 任务输出支持可靠的 UTF-8 增量读取，返回请求偏移和实际偏移。
- `project_list` 独立于启用状态报告实时文件系统健康状态。
- Shell 和结构化进程描述明确说明其拥有桌面用户完整权限，项目目录不是沙箱。
- 保留结构化进程、管道 stdin、任务持久化、Git 工作流、二进制传输、可恢复回收区、附件收件箱、主机诊断以及下游 MCP Resources/Prompts。

### 验证结果

- 共 149 个测试通过：132 个核心/服务测试和 17 个 MCP 端到端测试。
- 覆盖率：行 93.45%，分支 81.11%，函数 90.84%。
- 官方本地 Tunnel 控制面验证了 58 个工具、`project_list` 和字节一致的附件复制。
- 生产 Electron 六页面 UI 冒烟通过，无运行时错误或横向溢出。
