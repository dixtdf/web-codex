# Web Codex v0.3.0

> **Local/unreleased test build.** This is an unsigned local test build. It is not committed, pushed, or published. The `release-local/` 0.3.0 binaries contain the earlier Desktop QA build, not the later deep-test follow-up source changes recorded in `docs/VALIDATION.md`.

## English

Web Codex 0.3.0 expands the local workspace into a more complete coding and operations surface.

### Highlights

- 58 MCP tools, including downlink Resources and Prompts forwarding with 4 MB response limits.
- Project-contained Git worktree list/add/remove and explicit conflict discovery/resolution (`ours` or `theirs`).
- Git status, diff, log, branches, safe staging, and local commits without push, amend, or hook bypass.
- Structured process execution, interactive pipe stdin, idempotency, persisted task recovery, output pagination, and a configurable concurrent-process cap.
- File attributes, version-aware atomic text writes/patches, copy conflict strategies, deletion impact previews, recoverable trash, and explicit backups.
- Redacted JSON connection diagnostics.
- Stronger privacy handling for ChatGPT request metadata and existing retained JSONL logs.

### Verification

- 149 tests total (132 core/service + 17 MCP end-to-end) passed, including Desktop QA and deep-test regressions for UTF-8 boundaries, move-overwrite protection, deletion dry-run/CAS, strict schemas, search ignores/cursors, task output, project health, and structured errors.
- Official local Tunnel control plane verified `server/discover`, 58 tools, `project_list`, and binary attachment copy.
- Coverage: 93.45% lines, 81.11% branches, 90.84% functions.
- Packaged Electron UI smoke passed for six pages, attachment inbox, diagnostics, and discovery.

### Limitations

Packages are unsigned. No interactive ChatGPT browser automation runs in CI. Full PTY, automatic updates, OS-level sandbox/quota enforcement, macOS/Linux privileged helpers, and direct chat attachment ingestion remain separate future work.

Web Codex 0.3.0 将本地工作区扩展为更完整的编码与运维能力面。

### 主要更新

- 提供 58 个 MCP 工具，包括下游 Resources 与 Prompts 转发及 4 MB 响应限制。
- 项目内 Git worktree 列表/新增/删除，以及显式冲突发现与 `ours`/`theirs` 解决。
- Git 状态、差异、历史、分支、安全暂存和本地提交，不支持 push、amend 或绕过 hooks。
- 结构化进程执行、交互式管道 stdin、幂等、任务持久化恢复、输出分页和可配置并发上限。
- 文件属性、带版本校验的原子文本写入/补丁、复制冲突策略、删除影响预览、可恢复回收站和显式备份。
- 脱敏 JSON 连接诊断。
- 加强 ChatGPT 请求元数据与既有 JSONL 日志的隐私处理。

### 验证结果

- 共 149 个测试通过（132 个核心/服务测试 + 17 个 MCP 端到端测试），包含 Desktop QA 与深度测试的 UTF-8 边界、移动覆盖保护、删除预览/CAS、严格 Schema、搜索忽略/游标、任务输出、项目健康和结构化错误回归。
- 官方本地 Tunnel 控制面已验证 `server/discover`、58 个工具、`project_list` 和二进制附件复制。
- 覆盖率：行 93.45%，分支 81.11%，函数 90.84%。
- 打包 Electron 六页面、附件收件箱、诊断与发现协议 UI 冒烟通过。

### 限制

发布包未签名；CI 不执行交互式 ChatGPT 浏览器自动化；完整 PTY、自动更新、OS 级沙箱/配额、macOS/Linux 特权 helper 和聊天附件直接接入仍属于后续工作。
