# Web Codex v0.5.2

> **Published patch release.** Packages are unsigned.

## English

Web Codex 0.5.2 resolves the Windows CMD built-in completion report and includes three additional review rounds covering lifecycle races, protocol boundaries, configuration recovery, transfer safety, and audit persistence.

### Fixes

- CMD built-ins such as `echo CMD_1453` execute through a temporary UTF-8 script with explicit `exit /b`, preventing affected Electron environments from leaving simple commands open until timeout.
- External executables such as Node.js retain direct process-tree execution, avoiding additional CMD parent-process lifetime and cleanup issues.
- Direct ShellService and real MCP tests cover the four-second CMD case, quoted commands, Unicode output, exit metadata, non-zero exits, background process-tree termination, and cleanup.
- `docs/MCP_TOOLS.md` now explains how to restore, repath, disable, or remove unavailable project registrations.
- UTF-8 reads explicitly document backward alignment: `actualOffset <= requestedOffset`, `bytes = nextOffset - actualOffset`, and clients must continue with `nextOffset` rather than `requestedOffset + maxBytes`.
- Process, Tunnel, Gateway, and runtime startup/shutdown paths now handle stdin failures, spawn errors, concurrent starts, and emergency-stop coordination without false success states.
- IPv6 loopback URLs, full IPv4 loopback proxy bypass, disconnected MCP tool discovery, and duplicate downstream connections are corrected.
- Project instruction access, case-sensitive project paths, binary-read limits, whole-archive validation, and failed batch-upload rollback are enforced.
- Legacy MCP configuration fields and asynchronous persistence failures are handled safely; audit correlation identifiers are redacted and exports cannot overwrite active logs.
- Host uptime, native directory-open failures, task project selection, and renderer IPC error notifications now report accurate state.

### Verification

- The suite contains 175 tests (155 core/service and 20 MCP end-to-end): 172 passed and 3 platform-specific tests were skipped.
- Coverage: 93.21% lines, 81.26% branches, 90.1% functions.
- Official local Tunnel control plane verified version 0.5.2 and 58 tools.
- Production Electron UI smoke passed with `appVersion=0.5.2`, all six pages, and no runtime errors or horizontal overflow.

## 简体中文

> **已发布补丁版本。** 安装包未签名。

Web Codex 0.5.2 修复 Windows CMD 内建命令完成问题，并包含三轮额外复核，覆盖生命周期竞态、协议边界、配置恢复、传输安全和审计持久化。

### 修复内容

- `echo CMD_1453` 等 CMD 内建命令通过带显式 `exit /b` 的临时 UTF-8 脚本执行，避免受影响的 Electron 环境让简单命令一直运行到超时。
- Node.js 等外部可执行程序继续使用直接进程树执行，避免额外 CMD 父进程带来的生命周期和清理问题。
- ShellService 与真实 MCP 测试覆盖四秒 CMD 场景、引号命令、中文输出、退出元数据、非零退出、后台进程树停止及清理。
- `docs/MCP_TOOLS.md` 已说明如何恢复目录、修改路径、禁用或移除不可访问项目。
- UTF-8 读取明确采用向后对齐：`actualOffset <= requestedOffset`、`bytes = nextOffset - actualOffset`；客户端必须使用 `nextOffset` 续读，不能使用 `requestedOffset + maxBytes`。
- 进程、Tunnel、Gateway 和 Runtime 启停路径现在可正确处理 stdin 异常、spawn 失败、并发启动和紧急停止协调，不再误报成功状态。
- 修正 IPv6 回环 URL、完整 IPv4 回环代理绕过、断连 MCP 工具发现和重复下游连接。
- 加强项目指令访问、大小写敏感路径、二进制读取限制、整包 ZIP 校验和批量上传失败回滚。
- 安全处理旧 MCP 配置缺字段和异步持久化失败；审计关联标识统一脱敏，日志导出不能覆盖活动日志。
- 主机运行时间、原生目录打开失败、任务项目选择和渲染进程 IPC 错误通知现在会报告准确状态。

### 验证结果

- 共 175 项测试（155 项核心/服务测试和 20 项 MCP 端到端测试）：172 项通过，3 项按平台跳过。
- 覆盖率：行 93.21%，分支 81.26%，函数 90.1%。
- 官方本地 Tunnel 控制面验证了 0.5.2 和 58 个工具。
- 生产 Electron UI 冒烟确认 `appVersion=0.5.2`，六页面通过，无运行时错误或横向溢出。
