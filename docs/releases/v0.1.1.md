# Web Codex v0.1.1

## English

Web Codex 0.1.1 is the first complete release candidate with a reproducible cross-platform dependency lockfile.

This hotfix includes every feature from 0.1.0 and repairs the release workflow:

- Regenerated `package-lock.json` with all platform-specific esbuild optional dependencies, fixing `npm ci` on Windows, macOS, and Linux.
- Bundled checksum-verified official `openai/tunnel-client 0.0.19`; no system `openai` command is required.
- Verified 103 unit/service tests, 12 MCP end-to-end tests, the official local Tunnel protocol chain, and six-page production Electron UI smoke.
- Observed `/readyz = 200 ready` on the installed Windows application with real credentials. Interactive ChatGPT page validation remains a separate user-session check.

Download the package for your platform and architecture. Packages are unsigned in this release.

## 简体中文

Web Codex 0.1.1 是首个具备可复现跨平台依赖锁文件的完整发布候选版本。

本次热修复包含 0.1.0 的全部功能，并修复发布流程：

- 重新生成包含各平台 esbuild 可选依赖的 `package-lock.json`，修复 Windows、macOS 和 Linux 上的 `npm ci` 失败。

- 已通过 103 个单元/服务测试、12 个 MCP 端到端测试、官方本地 Tunnel 协议链和六页面生产 Electron UI 验证。
- Windows 安装版已使用真实凭证达到 `/readyz = 200 ready`；ChatGPT 页面内最终调用仍按独立用户会话验收。

请下载对应平台和架构的安装包。本发布版暂未进行代码签名。
